# Aishwarya M R — Personal Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — semantic page structure and portfolio content
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation, active section navigation and dynamic footer year

## Run locally
1. Download or clone this repository.
2. Open the folder in VS Code.
3. Open `index.html` with the Live Server extension, or open it directly in a browser.

## Before submitting
- Replace the GitHub profile links on each project card with the exact repository URLs if those repositories are public.
- Verify the LinkedIn profile URL and email address.
- Test at 375px, 768px and 1280px widths.
- Check all links and the browser console.

## Technologies
HTML5, CSS3, JavaScript (vanilla).

## Notes
Portfolio content is based on the supplied resume. Project cards link to the GitHub profile because individual project repository URLs were not included in the resume.
